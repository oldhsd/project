## 3️⃣ DEPLOY TO VERCEL (ALSO EASIEST)

```
1. Open: https://vercel.com
2. Click: "New Project"
3. Click: "Import Git Repository"
4. Paste: https://github.com/oldhsd/project
5. Click: "Import"
6. Click: "Environment Variables"
7. Add these 8 variables:
   - MONGODB_URI = (your MongoDB URL)
   - NEXTAUTH_SECRET = (generate random string)
   - NEXTAUTH_URL = https://your-vercel-url.vercel.app
   - NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME = (your name)
   - CLOUDINARY_API_KEY = (your key)
   - CLOUDINARY_API_SECRET = (your secret)
   - GMAIL_USER = (your email)
   - GMAIL_PASSWORD = (your app password)
8. Click: "Deploy"
9. Wait 2-3 minutes
10. Get live URL! 🎉
```

## 🆘 IF SOMETHING GOES WRONG

**"bash: command not found"**
- Use `sh` instead of `bash`
- Or use the manual commands in GITHUB_PUSH_GUIDE.md

**"Authentication failed"**
- Make sure you're pasting the token correctly
- Use a valid token value such as: `YOUR_GITHUB_TOKEN_HERE`

**"Repository not found"**
- Check URL is: https://github.com/oldhsd/project.git
- Check repo exists on GitHub
